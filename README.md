## ⚡ Engineering Philosophy

I focus on building software that goes beyond working code — systems that are **maintainable, scalable, secure, and production-ready**.

- **Backend Engineering:** Designing robust REST APIs, modular services, enterprise applications, and microservices using Java, Spring Boot, Node.js, and NestJS.
- **Cloud Architecture:** Deploying containerized workloads, designing isolated Google Cloud VPC environments, and configuring secure VPN-based connectivity.
- **DevOps & Infrastructure:** Automating deployments, managing Docker-based environments, and working with Kubernetes, Linux, and Bash.
- **Data & Persistence:** Building data-driven applications and working with MongoDB and enterprise data pipelines.
- **Exploring MLOps & AI Infrastructure:** Developing expertise in model deployment, ML pipelines, distributed training, vector databases, and cloud-native infrastructure for AI workloads.
